CONVEX 업데이트

펌웨어와 GIF 슬롯을 브라우저에서 바로 기기에 전송합니다.

연결되지 않음
이 브라우저는 지원하지 않습니다. WebHID 가 필요하므로 Chrome 또는 Edge 를 사용해 주세요. (Safari · Firefox 는 WebHID 를 지원하지 않습니다)
아래 파일 다운로드 는 모든 브라우저에서 사용할 수 있습니다.
이 펌웨어는 웹 업데이트를 지원하지 않습니다. 기기는 연결되었지만 업데이트 프로토콜에 응답하지 않습니다. 웹에서 바로 전송하려면 먼저 펌웨어를 업데이트해야 합니다.
  1. 펌웨어 탭에서 .uf2 파일을 내려받습니다.
  2. 기기를 부트로더 모드로 진입시킵니다.
  3. 나타난 USB 드라이브에 .uf2 를 복사합니다. (드라이브에 바로 쓰기 버튼을 쓰면 자동으로 복사됩니다)
업데이트 후 다시 연결하면 이 안내가 사라집니다.

LCD 해상도는 284 × 76 입니다. 다른 크기는 넣을 때 맞춰 줍니다. 파일을 이 창에 끌어다 놓아도 됩니다. 슬롯당 최대 약 2MB.

예제 불러오기 — · · · (내려받지 않고 바로 선택됩니다)

최대 16바이트 (한글 5자 정도)

기기를 연결하면 현재 버전을 보여줍니다
    전송이 끝나면 기기가 스스로 재시작하면서 펌웨어를 적용합니다. 적용 중에는 케이블을 뽑지 마세요. 전송에 실패해도 기존 펌웨어는 그대로 남아 있어 다시 시도하면 됩니다.
    연결하면 현재 시간을 보여줍니다

    기기의 RTC 는 백업 배터리로 유지됩니다. 시간이 어긋나 있으면 PC 시간으로 동기화 를 누르면 됩니다.
    기기가 재시작되면서 USB 드라이브로 잡힙니다. 여기에 .uf2 를 복사하면 펌웨어나 GIF 가 설치됩니다. 원래대로 돌아오려면 케이블을 다시 꽂거나 드라이브에 .uf2 를 복사하면 됩니다.
